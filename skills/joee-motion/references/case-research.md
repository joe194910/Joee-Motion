# 合规案例研究与规律蒸馏

案例研究只能记录公开合法元数据、用户手动提供的授权资料和明确允许使用的字幕或媒体。不得绕过平台限制、批量下载第三方视频或把公开可看等同于可复制。

使用 `jm case-add` 保存来源、访问方式、授权、时间、媒体哈希和指标局限。使用 `jm pattern-add` 记录触发条件、建议、不适用条件、支持案例、反例、证据等级、置信度和测试状态。

`candidate` 规律不能进入新项目规划。只有具备至少两个支持案例、一个反例并达到 cross-case 或 tested 证据等级的 `verified` 规律，才允许被 `jm plan` 检索和记录到项目来源中。
