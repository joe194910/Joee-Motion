# 交付质量检查

渲染前检查 Schema、稳定场景 ID、连续时间轴、画面与口播语义、主题硬编码、候选方向差异、素材权利、文件存在性、图片/视频组件匹配、事实来源、当前项目配音、实测片段时长和至少三个语义 cue。

渲染后使用 FFprobe 和 FFmpeg 检查目标分辨率、帧率、时长、视频轨、音频轨、SRT 边界、开场与结尾黑屏以及长静音，并输出 `qa/report.json` 和 `out/render-manifest.json`。

自动检测不能替代正常速度观看。文字裁切、闪帧、知识是否误导、声音艺术、节奏、原创性和商业审美必须由真实成片和人工审片决定；没有证据时标记 `not_evaluated`。
