# 创意方向流程

至少生成两个在叙事结构、布局、材质、运动语言和核心记忆镜头上有明显差异的候选方向。只改变色板不构成新方向。

候选方向写入 `creative-directions.json`，选中方向写入 `treatment.json`，并保证导演处理方案和分镜使用同一个核心场景 ID。

方向中的配色由项目内容稳定派生；每个场景还需要内容驱动的布局变体。统计组件和布局重复率，拒绝连续使用同一种居中构图。

运行 `jm plan` 后读取 `visual-assets.json`。仅为能建立真实情境、主体或空间深度的场景生成图片；数据、公式、机制和分档关系优先使用程序化动态图形。图像提示词必须延续同一风格圣经，并明确禁止图片内文字、Logo、浮动卡片、仪表盘和无关装饰。

把生成图作为可动画的场景材料：全画幅裁切、前中后景视差、遮罩揭示、焦点转移或局部推拉。不要把图片缩进一个圆角卡片再配大段文字。

需要更高差异度时，可以在用户明确提供模型并确认费用后运行 `jm creative-enhance`。AI 只能调整视觉母题、候选方向、组件、布局和核心记忆镜头，不得修改口播、事实、数字、场景 ID 或时间轴。所有输出必须经过 Schema 和项目预检。
