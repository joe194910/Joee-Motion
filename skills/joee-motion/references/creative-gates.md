# 创意与语义门槛

以下任一条件不满足时，必须阻止最终渲染：

1. 独立方向：项目具有内容专属的视觉论点，而不是只更换配色或文字。
2. 语义一致：场景文字、口播、图解、数据和素材表达同一个陈述。
3. 通用组件：组件内没有题材专属标签、案例、数字或结论。
4. 素材适配：素材包含权利、哈希、用途和场景关联，文件存在且媒体类型正确。
5. 叙事递进：场景承担不同作用并走向唯一的核心记忆镜头；连续居中卡片不是合格方案。
6. 工艺准备：字体、间距、安全区、对比度、转场、声音 cue 和故障兜底在渲染前已经定义。
7. 真实状态：原型、未经审片的草稿和启发式规划必须如实标记。

门槛失败时返回准确的场景 ID 和修复要求，不能通过换颜色或堆特效掩盖问题。
